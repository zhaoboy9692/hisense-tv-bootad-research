## 三、广告组件架构（谁在干活）

### 1. com.hisense.service.ad（uid 10000，/data/app）— 广告总控 + 素材下载
- 反编译确认（`analysis/service_ad_src/`）：
  - `util/BootUtils.java`：开机广告引擎。区分 **冷开机(BOOT)** 与 **STR 待机唤醒** 两套素材；负责把下载好的素材 copy 到 `/data/local/misc/`；开机动画结束后 **`deleteBootAD()` 自动删除广告文件**（除非 `persist.ad.debug.no_del_boot=true`）——这就是当前该目录下没有视频文件的原因：广告是"一次性投放、播完即删"。
  - `Const.java`：素材文件名常量（见上表）；`BOOT_AD_APK="com.hisense.bootad"`（第三方方案专用 APK，本机未装）。
  - 策略位：`POSITION_MAP_KEY_BOOT_AD = "ad_on_c"`。服务器配置（`KEY_POSITION`）：
    `{"code":"ad_on_c","period":"1440","hitTime":"360"}` → 每 1440 分钟（一天）评估一次投放。
  - 该应用同时承载 **几十个广告位**（片前广告 ad_vod_front、浮层 ad_float、暂停广告 ad_vod_pause、开机直达 ad_on_c、开屏 ad_op 等，见 `analysis/KEY_POSITION_dump.txt`）。
  - 内嵌阿里 TV 电商 SDK（tvtao_*）、MMA 广告监测 SDK。

### 2. com.hisense.service.hproxy（uid 10071）— P2P 下载代理
- 下载缓存目录：`/data/local/misc/hproxy_download/`、`/data/local/misc/a/`
- 实测缓存样本：`1552_433831-7680000-1920x1080-libx264*.ts`（1080p H.264 广告片，已提取到 `analysis/boot_ad_video.ts`，12.6MB，含 AAC 音轨）

### 3. com.hisense.business.ad（uid 10067，/data/app）— 淘 TV 开屏广告宿主
- `shared_prefs/com.hisense.business.ad_preferences.xml`：`sdk_splash_new_img` 指向阿里云 OSS 开屏图；接收 `ACTION_TV_TAO_SDK_INIT` 广播。
- 本质是电视淘宝 SDK + 开屏广告容器。

### 4. com.hisense.tv.advertisementproxy（系统 stub，4.5KB）+ SystemUI
- SystemUI odex 中发现 `com.jamdeo.tv.advertisementproxy.BOOTANIMATION` action、`SERVICE_BOOTANIM_EXIT`、`mIsBootAnimationExit`、`/data/local/misc/volume_ad`（音量条广告）——协调开机动画退出时机、加载各类系统级广告。

### 5. TVServices（com.jamdeo.tv.service，系统）
- odex 字符串：`setStartupAdvertMode`（开机广告模式）、`StartupLogoMode`、`FAST_SET_STARTUP_SOURCE`（开机直达信号源）、写 `/data/local/misc/startup_source_is_custom`（本机当前值 = 1，今天 18:44 开机时写入）。

## 四、广告数据流（完整链路）

```
海信广告云 ad-download.hismarttv.com
   ├─ /adland/sdkconfig_2024012201.xml     SDK 配置（KEY_RESOURCE，含天气包 MD5 等）
   ├─ /adland/lowfclist.json / membercheck.json / checkreport.json …
   └─ 广告素材（.ts/.mp4/.zip/.png）
        │  https 下载（另经 api-dynhost.hismarttv.com 域名调度）
        ▼
com.hisense.service.ad ←策略 ad_on_c（每日评估）
   │ 经 hproxy P2P 下载 → /data/local/misc/hproxy_download/
   │ 落地 → /data/local/misc/third_party_bootvideo.mp4 (+bootanimation.zip +跳转遮罩 png)
   ▼
下次开机：原生 bootanimation 优先级命中第 5/6 位 → 播放广告视频
   ▼
开机动画结束（service.bootanim.exit=1）
   ▼
deleteBootAD() 删除广告文件 + 清 DB（下次投放前该目录为空）
```

监测/上报域名：`cudetect.hismarttv.com`、`api-gps.hismarttv.com`、`bas-macplumber.hismarttv.com`、咪咕 `ggc.cmvideo.cn` / `inneradx-migu.iflysec.com`。

其它开关槽位（当前为空/关闭）：`settings system startupUrl`、`strStartupUrl`（运营自定义开机广告 URL）、`AD_DREAM_VIDEO_STATUS=0`（屏保视频广告）。

## 五、禁用开机广告方案（root，按推荐顺序）

### 方案 A：禁用广告组件（推荐，可逆）
```bash
adb connect <TV1-IP>:5555
adb shell
# 广告总控+下载（开机广告/片前广告/浮层广告的下载与策略）
pm disable-user --user 0 com.hisense.service.ad
# 淘 TV 开屏
pm disable-user --user 0 com.hisense.business.ad
# 系统级广告协调 stub
pm disable-user --user 0 com.hisense.tv.advertisementproxy
```
- 恢复：`pm enable <包名>`。
- **风险**：`com.hisense.service.ad` 还给桌面提供天气组件/消息浮层，禁用后聚好看桌面天气栏可能消失；不影响看电视和装当贝桌面。
- 建议逐个禁用并重启观察，先禁 `service.ad`（它才是开机广告素材的投放方）。

### 方案 B：清空并占位广告素材（精准、不动应用）
```bash
rm -f /data/local/misc/third_party_bootvideo.mp4 \
      /data/local/misc/third_party_bootanimation.zip \
      /data/local/misc/third_party_fast_bootvideo.mp4 \
      /data/local/misc/third_party_fast_bootanimation.zip \
      /data/local/misc/bootad_str_unveiling.png \
      /data/local/misc/bootanim_assets_home.png \
      /data/local/misc/bootanim_juui.png
```
广告服务再次投放时可能重建文件，配合方案 A（禁用投放方）即彻底。

### 方案 C：hosts 屏蔽广告域（断粮）—— ✅ 已于 2026-10-06 执行并验证生效
```bash
mount -o remount,rw /system          # 实测 hsc SELinux 域允许，成功
echo -e "127.0.0.1 ad-download.hismarttv.com\n::1 ad-download.hismarttv.com" >> /system/etc/hosts
sync && mount -o remount,ro /system
```
- **实测结果**：remount 成功（SELinux Enforcing 但 hsc 域有权限）；`/system/etc/hosts` 追加两条记录后，设备上该域名解析从 `111.62.101.235` 变为 `127.0.0.1`，对照组 `www.hismarttv.com` 解析正常（无误伤）。
- 修改持久化在 /system 分区，重启依然有效；OTA 升级覆盖 /system 后会失效，重新执行即可。
- 原始 hosts 备份：电视 `/data/local/hosts.bak`、Mac `analysis/hosts.bak`。恢复方法：remount rw 后用备份覆盖。
- 说明：该域名是广告 SDK 配置（sdkconfig）+ 广告素材/天气包的下载源（KEY_RESOURCE 中写明）。广告策略另有业务接口通道，若仍有个别广告走其他 CDN，可按需追加 `cudetect.hismarttv.com`（监测上报）等域名到 hosts。

### 方案 D：静态第一屏改图/去声（可选）
`/tvconfig/boot.ini` 控制 `boot0.jpg/boot0.mp3`（`MUSIC_ON=1` 可改 0 关开机音乐）。该分区 ext4 可写：
```bash
mount -o remount,rw /tvconfig   # 大多数情况默认已 rw
cp /sdcard/自定义图.jpg /tvconfig/boot0.jpg
```

### 不推荐
- 直接 `rm` 卸载 /data/app 下的广告 APK：OTA 升级或市场自愈可能回装，`pm disable-user` 更干净。
- "开机直达信号源"（FAST_SET_STARTUP_SOURCE）只能缩短桌面加载，不能跳过 bootanimation 阶段广告。

## 七、第二台电视（Hisense 43V1F-R，Android 9 / MT5862）处理记录 2026-10-06

### 提权尝试结果：未获得 root（审计过程）
| 审计项 | 结果 |
|---|---|
| adb 属性 | ro.secure=1 / ro.debuggable=0 / ro.adb.secure=1，adb root 不可用 |
| setuid 程序 | /system /vendor 下**无任何** setuid root 程序 |
| su / mtk-su | 不存在（/system/xbin 为空） |
| 内核 | 4.9.118（2023-09 构建），补丁级别 2020-05-05，CVE-2019-2215 类已含修复 |
| SELinux | **Permissive**（宽容模式，无强制约束） |
| init 残留 | `root-tool` 服务（user root）存在但 `root_tools.sh` 脚本已被官方删除，触发行已注释——死路 |
| MtkRmInitServer | 实为 MTK **Resource Manager**（资源仲裁），无命令执行面 |
| hsc (11KB) | 读 `ro.secure` 决定 adbd 是否以 root 启动的开关程序，受只读属性限制 |
| hstvos/hspocean/fast_connect | 无 system()/popen()/exec* 导入，无外部命令执行点 |

### 无 root 实施的方案（已生效）
```bash
pm disable-user --user 0 com.hisense.service.ad     # 广告总控（enabled=3 已确认）
pm disable-user --user 0 com.hisense.business.ad    # 淘TV开屏（enabled=3 已确认）
pm disable-user --user 0 com.hisense.service.hproxy # 下载代理（enabled=3 已确认）
rm -f /data/local/misc/bootanim_assets_home.png /data/local/misc/bootanim_juui.png
# 说明：/data/local/misc 在该机型为 drwxrwxrwx 且无 sticky 位，shell 可直接删除广告素材
```
- 恢复：`pm enable <包名>`；禁用状态持久化于 /data/system/packages.xml，重启不失效。
- 该机无 AdvertisementProxy（Android 9 架构不同），广告链以 service.ad 为核心，已断。
- 私人 DNS 方案（`private_dns_mode=hostname` + `private_dns_specifier=dns.adguard.com`）：**已尝试并回滚**。实测该网络环境 DoT(853) 出口不通，严格模式导致整机 DNS 失败，已按用户要求还原为 off——此方案在该网络环境不可用，勿再开启。

### 补充：禁用后仍见广告的原因与最终修复（同日 20:56）
- 现象：禁用三个广告包后用户待机再开机，广告依旧。
- 原因：该机开机/唤醒广告视频缓存在 **`/bootad/local/misc/`**（shell 属主、777 可写）：
  - `third_party_bootvideo.mp4`（冷开机，12.8MB，16s）
  - `third_party_fast_bootvideo.mp4`（待机唤醒，12.8MB）
  - 均为禁用前（20:31）已下载完成的缓存；bootanimation 每次开机/唤醒都会播放已有缓存，与下载方是否被禁用无关。
- 修复：两个缓存视频已删除（备份：`analysis/tv2_boot_ad.mp4`，抽帧 `tv2_boot_ad_frame_1/2.jpg`——画面含"按返回键跳过 08 秒"倒计时，为海信标准开机广告 UI）。
- 该机无固件内置广告视频（`/system/media/` 下只有默认开机动画 zip），缓存清空 + 下载方禁用后，开机/唤醒将直接显示默认海信 Logo 动画。
- 注意：`/bootad/local/misc/` 对 shell 可写是双刃剑——日后如需彻底防重建，可在禁用广告包的前提下定期清理该目录。
